    Send iPhone notifications to the laptop ›

    Needs iOS 27. In the Shortcuts app you make one shortcut, then one automation per app (WhatsApp, Instagram, Gmail…). Copy these two values first:

    1. Shortcut: New shortcut named Tell Cat. Add Get Contents of URL and paste the first value as the URL. Show More → Method POST. Header: X-Cat-Key = the second value. Request Body JSON with text fields app, title and body. Set title and body to Shortcut Input → Title and Body, and app to Shortcut Input → App if your iPhone offers it (otherwise leave it out).
    2. Automation: Automation → New → Notification → pick an app → Run Immediately. Action: Run Shortcut → Tell Cat, with Shortcut Input as the input. Repeat for each app you want on the laptop.
    3. iPhone battery on the island (optional): a second shortcut posting JSON battery = Get Battery Level and charging = Is Charging to the same address ending in /api/phone. Run it from automations like Battery Level and Charger.
    4. Focus sync (optional): Automation → Focus → Work → when turning on: Get Contents of URL, POST to the address ending in /api/focus?m=25; when turning off: /api/focus?m=0.

    Your key is private: anyone with it and access to your Tailscale could send to this laptop.
